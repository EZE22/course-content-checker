# Lab 1: Calculator

## Problem Statement

Build a small command line calculator in Python. It reads two numbers and an operation from the user, then prints the answer.

The goal is to practice variables, functions, and error handling together. Keep the program short and easy to read.

## Requirements

The calculator must meet each requirement listed in the table below.

| Requirement | Detail |
| --- | --- |
| Operations | Support add, subtract, multiply, and divide |
| Input | Ask the user for two numbers and an operation |
| Functions | Put each operation in its own function |
| Errors | Show a friendly message when dividing by zero |
| Tests | Include at least four pytest tests |

## Grading Rubric

Your work is graded on the criteria below, and the points add up to 100.

| Criterion | Points |
| --- | --- |
| All four operations work | 40 |
| Each operation has its own function | 20 |
| Division by zero is handled | 15 |
| Tests are included and pass | 15 |
| Code is clear and well named | 10 |
