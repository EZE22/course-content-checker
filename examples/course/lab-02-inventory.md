# Lab 2: Inventory

## Problem Statement

Build a small inventory tracker in Python. It keeps a list of items and how many of each item are in stock.

The goal is to practice loops, files, and error handling together. Save the inventory to a file so it survives between runs.

Start small. Get adding and reporting to work first, then add saving.

## Requirements

The tracker must meet each requirement listed in the table below.

| Requirement | Detail |
| --- | --- |
| Add items | Let the user add an item with a count |
| Remove items | Let the user remove some or all of an item |
| Report | Print every item and its count |
| Saving | Write the inventory to a file and load it at start |
| Errors | Show a friendly message when the file is missing |
| Quitting | Let the user leave the program cleanly |
| Tests | Include at least three pytest tests |
