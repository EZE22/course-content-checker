# Article 1: Variables

This is the first article in the course, so there is no earlier article to review. Here we learn how Python stores values.

## What Is a Variable

A variable is a name that points to a value. You create one by writing a name, an equals sign, and a value, such as `age = 30`.

Names should describe the value they hold. A name like `total_price` is easier to read than `x`.

## Common Mistakes

The table below lists mistakes that beginners often make with variables.

| Mistake | Better habit |
| --- | --- |
| Using a name like `x` for everything | Pick a name that describes the value |
| Starting a name with a number | Start with a letter or an underscore |
| Mixing up `=` and `==` | Use `=` to store and `==` to compare |

## Try It Yourself

1. Create a variable called `name` and give it your first name.
2. Create a variable called `age` and give it a number.
3. Print both variables with `print`.

## Why This Matters for an FDE

A forward deployed engineer reads other people's scripts all the time. Clear variable names make that reading faster and safer.
